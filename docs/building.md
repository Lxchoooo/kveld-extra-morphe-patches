# Building & Development

## Prerequisites

- **JDK 17+** (JDK 21 Temurin recommended)
- **Gradle** via the included `./gradlew` wrapper
- **Android SDK** (`sdk.dir` in `local.properties` or `ANDROID_HOME`), used to compile the companion extension
- **GitHub Packages credentials** for the Morphe Gradle plugin: `gpr.user` / `gpr.key` in `~/.gradle/gradle.properties`, or `GITHUB_ACTOR` / `GITHUB_TOKEN`

## Build

```bash
./gradlew buildAndroid
```

Output: `patches/build/libs/patches-*.mpp`.

## Checks

```bash
./gradlew check
```

## In-Situ Patching Gate (Mandatory)

Every patch change must be validated by running the Morphe Patcher against the target APK with all of that app's patches active. The run must finish with 0 failed patches, 0 fingerprint mismatches, and 0 smali compile errors.

`<targetApp>` is the `id` of an entry in the `TargetApp` registry (`patches/src/main/kotlin/util/PatchExecutionTest.kt`). The runner looks for the APK in `candidate_apks/`, the repository root, and the user's download directory.

```bash
./gradlew runPatchTest -Papp=<targetApp>

# Explicit APK file
./gradlew runPatchTest -Papk=/path/to/app.apk

# Force every boolean patch option on
./gradlew runPatchTest -Papp=<targetApp> -PallOptions=true

# Also write a signed, installable APK
./gradlew runPatchTest -Papp=<targetApp> -Pout=candidate_apks/<app>_<version>_patched.apk
```

For bundle targets (`.apkm` / `.xapk`), the signed split APKs are written next to the output and prefixed with its name:

```bash
adb install-multiple -r candidate_apks/<app>_<version>_patched*.apk
```

## Patch Metadata

```bash
./gradlew generatePatchesList
```

> [!NOTE]
> `patches-list.json`, `patches-bundle.json`, `CHANGELOG.md`, and the README patch catalog are regenerated by the release pipeline (`.releaserc`). Do not edit or commit them by hand.

## Release

Releases run manually through the `Release` workflow (`workflow_dispatch`). semantic-release derives the version from Conventional Commits since the last tag and publishes the `.mpp` to GitHub Releases.
